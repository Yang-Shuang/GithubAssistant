## 由于我的git使用不是很熟练，项目还有大量的MD文件，导致git追踪打包大量数据时经常报错导致无法push，这里记录了一些我常用解决问题的手段。

git 初始化的两种方式

直接init
# 1. 重新初始化
git init

# 2. 彻底关闭换行符自动转换（核心：防止批量文件在内存流中损坏）
git config --local core.autocrlf false

# 3. 强制单线程打包（防止 32 线程并发导致磁盘 I/O 锁死）
git config --local pack.threads 1

# 4. 重新关联你的 GitHub 远程仓库
git remote add origin git@github.com:Yang-Shuang/github-assistant.git

# 5. 把本地的默认分支改成 main，与云端对齐
git branch -M main

clone
到上级目录
clone git@github.com:Yang-Shuang/github-assistant.git


分批提交
git config --local core.autocrlf false
git config --local pack.threads 1
git add data/readmes/[0-9_]*
git commit -m "更新readme 数字"
git push
git add data/readmes/[a-b]*
git commit -m "更新readme ab"
git push


彻底“格式化”本地的 Git 仓库（碎骨重塑）

Remove-Item -Path .git -Force -Recurse
(请放心，这一步只会删掉坏掉的 Git 缓存，你本地辛辛苦苦写好的 2000 多个代码文件绝对 100% 完好无损！)

git init

git remote add origin git@github.com:Yang-Shuang/GithubAssistant.git

git branch -M main

git add .

git commit -m "Initial commit: perfectly cleaned and initialized"

git push -u origin main --force
